벤다이어그램 · 상호 비판 · 순서도 · XYZ 도식과 사상가·양식 삽화로 시험지와 활동지 그림을 만드는 도구

교사용 출제·수업 자료v1.2.0 웹판
이 브라우저에만 자동 저장됩니다

사용 매뉴얼

왼쪽에서 그림 종류를 고르고 설정을 바꾼 다음, 글상자를 얹어 PNG로 저장하거나 복사해 한글 문서에 붙이세요.

01

그림 종류 고르기

왼쪽 위 탭에서 벤다이어그램·상호 비판·순서도·XYZ 좌표·사상가 인물·칼럼·양식 중 하나를 고르세요. 탭을 옮겨도 각 탭의 설정은 그대로 남습니다.

02

도식 설정하기

벤다이어그램은 원 개수, 영역 기호(A·B·C…), 빗금 무늬를 정하면 범례가 자동으로 만들어집니다. 상호 비판은 화살표를 하나씩 켜고 끌 수 있고, 순서도는 네 가지 틀 가운데 고른 뒤 문구를 고칩니다. XYZ 좌표는 꼭짓점마다 ㄱ·ㄴ·ㄷ 기호를 넣거나 비울 수 있습니다.

03

삽화 고르기

사상가 인물과 칼럼·양식 탭에서는 기출 삽화를 검색해 고릅니다. 목록 위의 인물만·갑·을 제거·말풍선 제거 단추로 편집용 그림만 골라 볼 수 있습니다. 목록에는 사상가 이름을 크게, 출처 시험을 작게 보여 줍니다.

04

글상자·표식 얹기

＋ 글상자로 말풍선이나 칼럼 안에 글을 넣고, ＋ 표식으로 (갑)·ㄱ·(가) 같은 기호를 붙이세요. 흰색 가림 상자는 그림에 남은 글자를 가립니다. 글상자를 누르면 아래에 설정 창이 열리고, 오른쪽 아래 파란 점을 끌면 크기가 바뀝니다. 선택한 글상자는 Delete 키로 지울 수 있습니다.

05

글자 위치 다듬기

✥ 글자 위치 옮기기를 켜면 도식 안의 이름·기호·범례를 끌어 옮길 수 있습니다. ↺ 위치 초기화로 원래 자리로 돌아갑니다.

06

저장·복사·인쇄

PNG 저장은 한글 문서에 넣을 이미지, 이미지 복사는 바로 붙여넣기용입니다. 인쇄용은 3배 이상을 권합니다. 해상도 옆에 출력 크기와 300dpi 기준으로 선명하게 넣을 수 있는 가로 폭이 나옵니다. 삽화는 원본 크기보다 크게 넣으면 흐려집니다. SVG 저장은 확대해도 선이 깨지지 않는 벡터 파일입니다.

07

작업 이어 하기

설정과 글상자는 이 브라우저에 자동 보관됩니다. 다른 컴퓨터에서 이어 하려면 작업 파일 저장으로 받은 파일을 작업 파일 열기로 불러오세요. 잘못 고쳤으면 ↶ 실행 취소(Ctrl+Z)로 되돌립니다.

· 그림의 한글 글꼴은 사용하는 컴퓨터에 설치된 글꼴(HY중고딕·맑은 고딕 / HY신명조·바탕 등)로 그려집니다. 알파벳 기호는 Times New Roman 계열을 씁니다.
· SVG 파일을 다른 컴퓨터에서 열면 그 컴퓨터의 글꼴로 바뀔 수 있습니다. 시험지에는 PNG를 권합니다.
· 이미지 복사가 되지 않는 브라우저에서는 PNG 저장을 이용하세요.
· 인물·양식 삽화는 (주)도서출판 길벗이 정리한 「윤리 기출문제 클립아트」(ver.260903) 수록 그림입니다.
