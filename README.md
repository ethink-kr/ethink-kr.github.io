# Ethink(에씽크) — GitHub Pages 사이트

Ethink(에씽크) 사이트입니다. 대표 코너는 「윤리로 읽는 뉴스 — 수업에 바로 쓰는 시사 윤리」와 「윤리로 읽는 책」입니다. 사이트 이름은 `_config.yml`의 `title`, 코너 이름은 `news_title`에서 바꿉니다. 새 글은 화·목·토 아침 9시에 한 편씩 올라가고, 2주에 한 번 그 사이 글을 한 호로 묶습니다. GitHub가 Jekyll로 자동 빌드하므로 따로 설치할 것이 없습니다. 비용은 들지 않습니다.

## 처음 한 번: 사이트 열기

1. github.com에 가입합니다. 아이디가 주소가 됩니다 (`아이디.github.io`).
2. 오른쪽 위 **+ → New repository**. 이름을 정확히 `아이디.github.io`로, **Public**으로 만듭니다.
3. 저장소 화면에서 **Add file → Upload files**. 이 폴더 안의 파일과 폴더를 통째로 끌어다 놓고 **Commit changes**. (`_site` 폴더는 올리지 않습니다.)
   - 숨김 파일(`.gitignore`)은 없어도 됩니다.
   - 꾸준히 쓰려면 GitHub Desktop 앱을 권합니다. 이 폴더를 저장소로 연결해 두면 저장 → Commit → Push 세 번 클릭으로 발행됩니다.
4. 저장소 **Settings → Pages → Build and deployment**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 두고 Save.
5. 1~3분 뒤 `https://아이디.github.io`에 사이트가 열립니다.

> 저장소 이름을 `아이디.github.io`가 아닌 다른 이름(예: `ethics`)으로 만들었다면 `_config.yml`의 `baseurl`을 `"/ethics"`로 바꿔야 합니다.

## 처음 한 번: 내 정보 고치기

`_config.yml` 맨 위의 `author`(표시 이름), `author_role`, `email`만 고치면 전체 페이지에 반영됩니다.

## 새 글 올리기 (화·목·토 아침 9시 예약 발행)

1. `_items/2026-10-24/` 폴더를 만들고 `_templates/새-항목.md`를 `1.md`로 복사해 채웁니다. 본문 소제목은 `#####`로 씁니다.
2. 앞머리 `date`를 `2026-10-24 09:00:00 +0900`처럼 발행 시각으로 적습니다. 미리 올려 두어도 그 시각 전에는 사이트에 보이지 않습니다.
3. 올리면(Commit·Push) GitHub Actions가 사이트를 다시 만듭니다. 화·목·토 09:00과 09:30에도 자동으로 다시 만들어서, 예약한 글이 그때 나타납니다. (저장소 Settings → Pages의 Source가 「GitHub Actions」여야 합니다.)
4. 홈 「최신 글」에 카드로 보입니다. `question`이 카드의 두 번째 줄에 나오니 꼭 채웁니다.
5. 인스타그램(@ethink.kr)에는 글마다 카드 뉴스(여러 장)를 올립니다. 문안 `_items/날짜/ig-cards-N.yml`을 `_tools/ig-cards.cjs`로 이미지로 만들고(`assets/ig/`), 문안에 `approved: true`가 있어야 자동 게시되며, 웹 글이 나간 다음 날 아침 9시(수·금·일)에 올라갑니다. 웹 글은 그 사이에 고칠 수 있고, 인스타그램은 올리면 지우고 다시 올려야 하기 때문입니다. 규칙은 `_tools/WRITING_GUIDE.md` 6절에 있습니다.

## 검색 등록

## 뉴스레터 (2주에 한 번)

호수와 묶음 페이지는 없습니다. 2주에 한 번, 그사이 사이트에 올라온 글(시사 윤리·윤리로 읽는 책)을 모아 뉴스레터로 보냅니다. 각 글의 주소(`/weekly/날짜/번호/`)를 그대로 링크합니다.

## 「윤리로 읽는 책」 새 글

1. `_templates/새-책-글.md`를 복사해 `_reads/` 폴더에 `YYYY-MM-DD-짧은영문이름.md`로 저장합니다. 예: `_reads/2026-10-24-justice.md` → 주소 `/reading/2026-10-24-justice/`
2. 표지 이미지가 있으면 `assets/reading/`에 넣고 `cover:`에 경로를 적습니다(가로 600px 정도).
3. 밑줄 친 문장은 `underlines:`에 한 줄씩 넣습니다. 인용은 꼭 필요한 만큼 짧게 둡니다.
4. `date`를 `YYYY-MM-DD 09:00:00 +0900`으로 적습니다. 그 시각 전에는 사이트에 나타나지 않습니다.
5. 책 글은 정기 발행이 아닙니다. 읽은 책 가운데 골라 쓸 때마다 올리며, 뉴스의 화·목·토 일정과 상관없습니다. 바로 올릴 때는 `date`를 올리는 시각보다 앞선 시각으로 적습니다.

## 좋아요·찜·공유하기

- 글마다 「좋아요」, 「찜」, 「공유하기」 단추가 있습니다.
- 「공유하기」를 누르면 카카오톡·Facebook·X·Threads·링크 복사(고리 기호) 메뉴가 열립니다. 카카오톡은 휴대폰에서 기기 공유 창을 열고, 컴퓨터에서는 링크를 복사합니다.
- 「찜」은 독자의 브라우저에만 저장되고, 위쪽 메뉴 「찜한 글」(/saved/)에서 모아 봅니다.
- 「운영자에게 의견 보내기」(/board/)는 비공개 게시판입니다. 상단 메뉴에는 없고, 아래쪽(푸터)과 글마다 있는 「운영자에게 의견 보내기」 버튼으로 들어갑니다. 방문자는 제목·본문·숫자 4자리 비밀번호만 입력하고, 글은 통계 시트의 「운영자 의견」 탭에 쌓입니다(예전 구글 설문 의견 양식은 쓰지 않음).
  - 공개: 시트에서 '승인'에 체크하고 '숨김'에 체크하지 않은 글의 제목·날짜·답변 여부만 목록에 보입니다.
  - 본문과 댓글: 글 번호와 비밀번호를 맞힌 글쓴이만 봅니다(5번 틀리면 1시간 잠금). 운영자는 시트의 '댓글' 칸에 답을 씁니다.
  - 새 글 알림: Apps Script가 hello@ethink.kr로 메일을 보냅니다. 처음 한 번 편집기에서 setupBoard를 실행해 메일 권한을 승인해야 합니다.
  - 스팸 막기: 같은 브라우저 10분에 1건·하루 5건, 사이트 전체 하루 60건, 숨은 입력란(자동 등록 프로그램 차단).
- 좋아요 수는 구글 시트 「윤리로 읽는 뉴스 · 좋아요 카운터」에 쌓입니다. `_config.yml`의 `likes_api:`를 비우면 하트가 숨겨집니다.

## 공유 썸네일(OG 이미지)

메신저·SNS에 주소를 붙이면 뜨는 미리보기 그림은 `assets/og/` 폴더에 있습니다.
- `site.jpg` 홈·기본, `about.jpg` 소개, `날짜.jpg`(예: `2026-10-16.jpg`)는 해당 날짜 글의 미리보기.
- 글마다 그림을 따로 두려면 `assets/og/날짜.jpg`(1200×630)를 넣습니다. 없으면 `site.jpg`가 대신 쓰입니다.
- 한 번 공유된 주소의 그림은 카카오톡 등이 저장해 두므로, 바꾼 그림이 바로 보이지 않을 수 있습니다.

## 방문 통계 (운영자 전용)
- 페이지가 열릴 때마다 `_includes/page-actions.html`이 좋아요와 같은 Apps Script 웹 앱에 `act=hit`로 한 줄을 보냅니다(주소, 제목, 코너, 브라우저별 무작위 번호, 유입 정보, 사이트 안 이전 페이지). 이름·이메일·IP는 보내지 않습니다.
- 기록과 통계는 구글 시트 「Ethink · 방문 통계·좋아요」에 쌓입니다. 시트는 비공개라 운영자만 봅니다.
  - **통계** 탭: 요약(오늘·최근 7일·이번 달·전체), 코너별 방문자·조회수, 유입 경로, 글·페이지별 방문자·조회수, 사이트 안 이동, 일·주·월·연도별
  - **글목록** 탭: 주소마다 한 줄, 가장 최근 제목(제목이 바뀌어도 한 글로 셈)
  - **방문기록** 탭: 원자료
- 코너: 홈 / 윤리로 읽는 뉴스 / 윤리로 읽는 책 / 나와 닮은 사상가 / 윤리 채널 / 소개·만든 책 / 운영자에게 의견 보내기 / 찜한 글.
- 유입 경로는 ① 주소 끝의 `?from=표시` ② 카카오톡·인스타그램 같은 앱 안 브라우저 ③ 이전 사이트 주소 순서로 정합니다. 사이트의 공유 버튼과 링크 복사에는 `?from=kakao`, `?from=link` 등이 자동으로 붙고, 읽은 뒤 주소창에서는 지워집니다.
- 직접 링크를 걸 때 표시를 붙이면 경로가 구분됩니다: `?from=brunch`(브런치), `?from=blog`(네이버 블로그), `?from=insta`(인스타그램), `?from=channel`(길벗 카카오 채널), `?from=email`, `?from=qr`. 목록에 없는 표시는 '표시: 이름'으로 잡힙니다.
- 내 브라우저를 집계에서 빼려면 그 브라우저로 `https://ethink.kr/?nostats=1`을 한 번 엽니다(`?nostats=0`이면 다시 셉니다).
- Apps Script 코드 사본: `_tools/apps-script-Code.gs`. 코드를 바꾸면 편집기에 붙여 넣고 저장한 뒤, 기록 방식(`hit_`)을 바꿨을 때는 **배포 → 배포 관리 → 편집 → 새 버전 → 배포**로 같은 주소에 다시 배포합니다. 통계 탭을 다시 그리려면 편집기에서 `setupStats`를 실행합니다.
- Apps Script 웹 앱은 `c`, `sid`라는 이름의 항목을 받지 않습니다(예약어). 새 항목을 보낼 때 피해야 합니다.
